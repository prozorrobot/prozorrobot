# Prozorro Bot - Сайт лендинг

Рекламная страница для Telegram бота Prozorro Bot - современный одностраничный сайт для привлечения пользователей.

## 📁 Структура проекта

```
prozorro-bot-site/
├── index.html              # Главная страница
├── css/
│   └── style.css          # Стили сайта
├── js/
│   └── script.js          # JavaScript анимации
├── images/                # Папка для изображений
├── package.json           # Конфигурация Node.js
├── .htaccess              # Настройки Apache
├── robots.txt             # Для поисковых систем
├── sitemap.xml            # Карта сайта
└── README.md              # Этот файл
```

## 🚀 Запуск и развертывание

### Локально для тестирования:
```bash
# Установите зависимости
npm install

# Запустите сервер
npm start
```
Откройте: http://localhost:5000

### Размещение на хостинге:

**Рекомендуемые варианты:**

1. **Vercel** (бесплатно, автоматически):
   - Подключите GitHub репозиторий
   - Автоматическое развертывание при push

2. **Netlify** (бесплатно):
   - Перетащите папку проекта на netlify.com
   - Получите домен типа `prozorro-bot-site.netlify.app`

3. **GitHub Pages** (бесплатно):
   - Включите Pages в настройках репозитория
   - Доступ по адресу: `https://username.github.io/repo-name/`

4. **Обычный хостинг**:
   - Загрузите файлы через FTP
   - Убедитесь, что сервер поддерживает HTML/CSS/JS
